clawdog-widget-renderer

Schema-driven HTML widget renderer for ClawDog calculator surfaces. Vanilla JS, no framework, iframe-embeddable.

Available widgets

  • gl-detail-csv-uploader — Upload a GL Detail CSV per the ClawDog spec.

How to embed

Each widget renders standalone at its own URL. Embed in a host shell via iframe:

<iframe src="https://www.lodgeit.org/clawdog-widget-renderer/widgets/gl-detail-csv-uploader/"
        width="600" height="400"
        sandbox="allow-scripts allow-forms allow-same-origin"></iframe>

Documentation

See the README on GitHub for the full API surface, how to add a widget, and the JSON Schema → form rendering contract.
